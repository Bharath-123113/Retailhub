# RetailHub Release Notes

## Version 1.0.0

### Release Overview

Initial documented release of the RetailHub project.

### Features

- Application configuration management.
- Deployment configuration.
- Health-check configuration.
- Logging configuration.
- Git and GitHub collaboration workflow.

### Documentation Updates

- Updated project README.
- Improved deployment guide.
- Added Pull Request checklist.
- Documented application configuration parameters.
- Documented deployment script functionality.

### Configuration Details

- Application port: 8065.
- Database port: 5432.
- Health-check path: /health.
- Logging format: JSON.
- Deployment environment: dev.

### Known Limitations

- The current deployment script validates and displays configuration information.
- Actual application deployment functionality is not yet implemented in the script.
